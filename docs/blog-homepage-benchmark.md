# 个人博客首页布局与功能调研

调研日期：2026-08-21

目标不是复制某个站点，而是识别成熟个人主页反复采用的信息架构，再将其转译为“雲梦世界”的语言与视觉。

## 反复出现的模式

1. 首页开头先回答“这是谁、这里有什么”，而不是先展示完整内容目录。
2. 最新内容几乎总有独立入口；内容多的站点还会补充精选、热门、专题或标签。
3. 项目、文章和个人介绍通常是一级入口，导航不会平铺十几个同权链接。
4. Now、当前工作或最近状态让个人网站显得仍在持续维护。
5. RSS、邮件订阅或社交链接会在页面尾部再次出现，形成清晰收口。
6. 随机文章、主题词和精选路径能让旧内容重新被发现。
7. 强视觉站点也会保持主体 HTML 简单，互动细节不能阻断阅读与导航。

## 对雲梦世界的改版决策

### 采用

- 在世界地图后增加“云门导览”：说明王选默是谁、站点收纳什么，并给出阅读、项目、关于、随机漫游四条起步路径。
- 把桌面端七个并列境域收进“七境”菜单，同时保留笔记、项目、关于、工作台等高频入口。
- 恢复现有但被隐藏的“云村近况”，展示三篇最新笔记和精选项目。
- 增加内容数量、最近更新日期和当前推进状态，让首页具有持续生长感。
- 在内容区尾部增加 RSS 与云镜搜索入口，形成内容发现闭环。
- 随机漫游只使用少量原生脚本和现有内容链接，不引入新运行时依赖。

### 不采用

- 不添加无真实数据支撑的访问量、读者数或“社会证明”。
- 暂不添加需要第三方服务的邮件表单；现阶段用 RSS 更轻、更可靠。
- 不把首页改成通用作品集模板，保留全境地图、七境叙事和像素卷轴视觉。
- 不再增加大型动画库或首屏客户端组件，避免重新放大性能成本。
